# 🔒 端口访问权限详解

## 🌐 端口访问类型

### 1. 外部可访问端口 (External Ports)
```
互联网用户 → 服务器IP:端口
```

**特点：**
- 任何人都可以访问
- 需要防火墙开放
- 有安全风险

**常见外部端口：**
- **80** - HTTP (网页)
- **443** - HTTPS (安全网页)
- **22** - SSH (远程登录)
- **21** - FTP (文件传输)

### 2. 内部端口 (Internal Ports)
```
只能服务器内部访问
localhost:端口 或 127.0.0.1:端口
```

**特点：**
- 只能服务器自己访问
- 更安全
- 通常用于服务间通信

**常见内部端口：**
- **8000** - 你的后端API
- **3306** - MySQL数据库
- **27017** - MongoDB数据库
- **6379** - Redis缓存

## 🌐 HTTP vs HTTPS 详解

### HTTP (超文本传输协议)
```
客户端 ←→ 服务器 (明文传输)
```

**特点：**
- 数据明文传输
- 容易被窃听
- 端口：80
- 不安全

**传输过程：**
```
用户输入密码 → HTTP明文传输 → 服务器
(容易被黑客截获)
```

### HTTPS (安全超文本传输协议)
```
客户端 ←→ SSL/TLS加密 ←→ 服务器
```

**特点：**
- 数据加密传输
- 防止窃听和篡改
- 端口：443
- 安全

**传输过程：**
```
用户输入密码 → HTTPS加密传输 → 服务器
(即使被截获也无法解密)
```

## 🔐 SSL/TLS 加密原理

### 1. 握手过程
```
客户端 → 请求HTTPS连接
服务器 → 发送SSL证书
客户端 → 验证证书
双方 → 协商加密算法
建立 → 加密通道
```

### 2. 数据加密
```
原始数据 → 加密算法 → 密文 → 网络传输 → 解密 → 原始数据
```

## 🛡️ 安全最佳实践

### 1. 端口安全
```bash
# 只允许本地访问8000端口
iptables -A INPUT -p tcp --dport 8000 -s 127.0.0.1 -j ACCEPT
iptables -A INPUT -p tcp --dport 8000 -j DROP

# 关闭8080端口外部访问
iptables -A INPUT -p tcp --dport 8080 -j DROP
```

### 2. 防火墙配置
```bash
# 启用防火墙
ufw enable

# 只开放必要端口
ufw allow 80/tcp
ufw allow 443/tcp
ufw allow 22/tcp
```

### 3. 服务配置
```bash
# 修改后端服务只监听本地
# 在 app/server_run.py 中修改
"host": "127.0.0.1",  # 只允许本地访问
```

## 💡 理解要点

### 1. 端口访问权限
- **0.0.0.0** = 允许所有IP访问
- **127.0.0.1** = 只允许本地访问
- **:::** = IPv6的所有地址

### 2. HTTP vs HTTPS
- **HTTP** = 明文传输，不安全
- **HTTPS** = 加密传输，安全
- **SSL/TLS** = 加密协议

### 3. 安全原则
- 最小权限原则：只开放必要的端口
- 纵深防御：多层安全保护
- 定期检查：监控端口使用情况
