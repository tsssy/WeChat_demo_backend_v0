🎯 "打洞" 配置示例
==========================================

当前配置 (单一"洞"):
```nginx
# 所有请求都转发到8000端口
location / {
    proxy_pass http://localhost:8000;
}
```

多"洞"配置 (按路径分发):
```nginx
# API请求 → 后端服务
location /api/ {
    proxy_pass http://localhost:8000;
}

# 管理后台 → 管理服务  
location /admin/ {
    proxy_pass http://localhost:8080;
}

# 静态文件 → 文件服务
location /static/ {
    root /var/www/static;
}

# 前端应用 → 前端服务
location /frontend/ {
    proxy_pass http://localhost:3000;
}
```

🎯 分发机制可视化：
```
443端口 (外部入口)
    ↓
Nginx智能分发
    ↓
├── /api/* → localhost:8000 (后端API)
├── /admin/* → localhost:8080 (管理后台)  
├── /static/* → /var/www/static (静态文件)
├── /frontend/* → localhost:3000 (前端服务)
└── /* → localhost:8000 (默认后端)
```

负载均衡"洞" (多个后端):
```nginx
# 定义后端组
upstream backend {
    server localhost:8000;  # 后端1
    server localhost:8001;  # 后端2
    server localhost:8002;  # 后端3
}

# 自动分发请求
location / {
    proxy_pass http://backend;
}
```

💡 理解要点
==========================================

1. **"打洞"的本质**:
   - 外部端口 → 内部端口
   - HTTPS → HTTP (协议转换)
   - 用户无感知的转发

2. **安全优势**:
   - 隐藏内部结构
   - 统一安全控制
   - SSL终止处理

3. **性能优势**:
   - 静态文件缓存
   - 负载均衡
   - 压缩优化

4. **管理优势**:
   - 统一入口
   - 便于维护
   - 灵活配置

你的理解完全正确！Nginx就是一个智能的"端口转发器"。
